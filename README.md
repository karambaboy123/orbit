# Orbit — AI Workflow Tool

> Minder nadenken. Meer bouwen. Maak van elk idee direct een uitvoerbare AI-workflow.

**Orbit** is een gratis, lokale web-app die je helpt om opdrachten, ideeën en bestanden om te zetten naar duidelijke AI-prompts, checklists en gestructureerde workflows — zonder technische kennis.

🌐 **Live demo:** [karambaboy123.github.io/orbit](https://karambaboy123.github.io/orbit/)

---

## Wat kan Orbit?

| Functie | Beschrijving |
|--------|-------------|
| ✏️ **Nieuwe Opdracht** | Analyseer opdrachten en splits ze op in subopdrachten en checklists |
| ⚡ **Prompt Genereren** | Bouw krachtige AI-prompts van een simpele beschrijving |
| 📤 **Bestand naar AI** | Upload tekst of briefings en laat Orbit ze analyseren |
| 📥 **AI naar Checklist** | Zet een AI-antwoord om naar een interactieve checklist |
| 🌐 **AI Launcher** | Start direct bij ChatGPT, Gemini, Claude of Copilot |
| 🎯 **Portfolio en Doelen** | Beheer persoonlijke doelen en mijlpalen |
| 📓 **Notities** | Bewaar ideeën en AI-antwoorden in je logboek |
| 📊 **Weekreview** | Reflecteer op je week en plan je volgende stap |

---

## Kenmerken

- Alles in één bestand — geen installatie, geen server, geen database
- Lokale opslag — al je data blijft in je eigen browser (localStorage)
- 12 thema's — van Indigo Classic tot Neon Night
- 15 lettertypen — via Google Fonts instelbaar
- Professionele iconen — Lucide, Material Symbols of Phosphor
- Gemini AI — optionele gratis AI-integratie via Google API
- Responsive — werkt op desktop en mobiel
