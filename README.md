## Wat is Orbit?

**Orbit** is een gratis, installeerbare web-app (PWA) die je helpt opdrachten, ideeën en bestanden om te zetten naar duidelijke AI-prompts, checklists en gestructureerde workflows — volledig in je browser, zonder installatie of account.

---

## Functies

| Functie | Beschrijving |
|---|---|
| **Nieuwe Opdracht** | Analyseer opdrachten en splits ze op in subopdrachten, checklists en taken |
| **Prompt Genereren** | Bouw krachtige AI-prompts van een simpele beschrijving |
| **Bestand naar AI** | Upload tekst of briefings en analyseer ze met AI-presets |
| **AI naar Checklist** | Plak een AI-antwoord en maak er een interactieve checklist van |
| **AI Launcher** | Start direct bij ChatGPT, Gemini, Claude of Copilot |
| **Portfolio & Doelen** | Beheer persoonlijke doelen en volg je voortgang |
| **Notities** | Bewaar ideeën en AI-antwoorden met Markdown-ondersteuning |
| **Weekreview** | Reflecteer op je week en genereer een weekplanning met AI |
| **Globale zoekfunctie** | Zoek direct door taken, notities en doelen (Ctrl+K) |
| **PDF Export** | Exporteer taken, checklists en notities als PDF |
| **Tags voor taken** | Label en filter je opdrachten op categorie |
| **Taak-templates** | Snelstart-sjablonen voor HBO, project, presentatie en meer |
| **AI Output naar Opdracht** | Plak ChatGPT-output en sla op als volledige analyseopdracht |

## Installeren als app (PWA)

Orbit is een Progressive Web App — installeer hem als echte desktop- of mobiele app.

**Desktop (Chrome of Edge)**
1. Ga naar [karambaboy123.github.io/orbit](https://karambaboy123.github.io/orbit/)
2. Klik op het installatie-icoon in de adresbalk
3. Klik Installeren — Orbit staat nu in je taakbalk

**Android**
1. Open Chrome en ga naar de site
2. Tik op het menu en kies Toevoegen aan startscherm

**iPhone (Safari)**
1. Open Safari en tik op het deel-icoon
2. Kies Zet op beginscherm

Updates worden automatisch op de achtergrond geladen. Geen herinstallatie nodig.

## Waarschuwing — Data wordt lokaal opgeslagen

> Al je data (taken, notities, doelen, instellingen) wordt opgeslagen in de **localStorage van je browser**.

| | |
|---|---|
| Volledig privé | Niets gaat naar een server |
| Werkt offline | Dankzij de ingebouwde service worker |
| Let op | Data verdwijnt als je je browsercache leegmaakt |
| Let op | Niet automatisch gesynchroniseerd tussen apparaten |

**Tip:** Maak regelmatig een backup via Instellingen → Gegevens & Export → Exporteer backup.

## Gemini AI (optioneel)

Orbit ondersteunt Google Gemini AI voor het automatisch genereren van weekplanningen, taakoverdrachten en prompt-verbeteringen.

Voeg je gratis sleutel in via **Instellingen → AI-instellingen**.  
Zonder sleutel werkt Orbit volledig offline met lokale alternatieven.

## Techniek

- Pure HTML, CSS en JavaScript — één enkel bestand, geen framework, geen build-stap
- Tailwind CSS via CDN
- Lucide, Material Symbols en Phosphor Icons — drie icoon-stijlen instelbaar
- Marked.js en DOMPurify voor veilige Markdown rendering
- Google Fonts — 15+ lettertypen
- Service Worker voor offline support en automatische updates
